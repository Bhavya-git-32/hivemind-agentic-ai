# 🚀 HiveMind

### Enterprise Multi-Agent AI Knowledge Platform

HiveMind is a modular Agentic AI platform that centralises enterprise knowledge and routes user queries to specialised AI agents for documentation, source code, incidents, and domain expertise.

## Highlights

* Multi-Agent Architecture
* FastAPI REST APIs
* JWT Authentication
* Enterprise Knowledge Search
* Analytics Dashboard APIs
* Search History
* Upload Knowledge API
* Swagger Documentation
* Modular Service Architecture
* Production-ready Project Structure
